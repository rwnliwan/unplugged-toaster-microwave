## The line

> Leaving you for the microwave.

30 characters. The toaster is not asking for a better setting or a cleaner crumb tray — it is leaving for another appliance entirely. The microwave is the one kitchen rival every toaster knows: faster, warmer, and already sitting on the same counter.

## How it works

`main.ts` (Node 22) writes the line to `/output/entry.txt` (or `$ENTRY_OUTPUT` when set). No dependencies, no network, deterministic output.

## Run it

```sh
node main.ts
cat /output/entry.txt
```
